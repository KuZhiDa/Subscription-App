
# Subscription App

Единый кабинет для управления активными подписками пользователя и настройки их параметров с автоматизированной подсистемой уведомлений на основе универсального веб-приложения.

## Область MVP

### Основные функции
- Регистрация и авторизация пользователей
- Создание, просмотр, изменение и удаление подписок
- Учёт платежей и история платежей
- Уведомления о предстоящем продлении подписок
- Отчёты о расходах
- Настройки уведомлений
- Обмен данными с 1С
- Автоматизированные тесты

### Архитектура
- Frontend: React + TypeScript
- Backend: NestJS
- ORM: Prisma
- База данных: PostgreSQL
- Сервис уведомлений: Go + Gin
- Брокер сообщений: RabbitMQ
- Окружение: Docker Compose
